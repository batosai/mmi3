# AdonisJS Lab : Créer votre application

**BUT 3 MMI : Atelier de développement web**

- **Durée :** 2 séances de 3h30 (7 heures)
- **Modalité :** À distance
- **Framework :** AdonisJS
- **Intelligence artificielle :** Autorisée et encouragée

## Présentation

Pendant ces deux séances, vous allez concevoir et développer une application web avec le framework **AdonisJS**.

L'objectif est de mettre en pratique vos connaissances, de découvrir de nouvelles fonctionnalités et d'expérimenter une autre manière de développer, notamment avec l'aide de l'intelligence artificielle.

Vous êtes libres d'utiliser les outils d'IA de votre choix (ChatGPT, Claude, Codex, Copilot, etc.) pour vous accompagner dans la conception, le développement et la résolution des problèmes rencontrés.

**Important :** l'utilisation de l'IA ne vous dispense pas de comprendre votre application. Vous devrez être capables d'en expliquer le fonctionnement lors de la présentation finale.

### Besoin d'aide ?

Même si cet atelier se déroule en autonomie et à distance, je reste disponible pendant les séances.

N'hésitez pas à me solliciter en **message privé (MP)** si vous avez des questions, si vous rencontrez des difficultés techniques ou si vous souhaitez échanger sur votre idée de projet.

L'objectif est d'apprendre et d'expérimenter, pas de rester bloqué sur un problème !

## Étape 1 : Créer votre dépôt GitHub

**À réaliser dès le début de la première séance.**

1. Connectez-vous à GitHub.
2. Créez un nouveau dépôt public et vide.
3. Donnez-lui un nom en rapport avec votre projet.
4. Ne générez pas de README, de `.gitignore` ou de licence lors de sa création.
5. **Transmettez-moi immédiatement l'URL de votre dépôt GitHub.**

Exemple : `https://github.com/votre-utilisateur/mon-projet`

Vous utiliserez ce dépôt pendant toute la durée du challenge pour versionner et partager votre travail.

## Étape 2 : Choisir votre projet

Vous êtes libres d'imaginer votre propre application web, à condition que le projet reste réalisable dans le temps imparti.

Si vous manquez d'inspiration, voici quelques propositions.

## Étape 3 : Développer votre application

Votre application devra respecter les contraintes techniques suivantes :

- Utiliser **AdonisJS** comme framework backend.
- Utiliser une base de données (SQLite recommandé).
- Exploiter **Lucid ORM** pour manipuler les données.
- Mettre en place des routes et des contrôleurs.
- Proposer des fonctionnalités de création, consultation, modification ou suppression de données (CRUD).
- Utiliser **VineJS** pour valider les données.
- Disposer d'une interface permettant d'utiliser l'application.

Vous pouvez utiliser Edge, Vue, React ou toute autre solution frontend compatible avec votre projet.

### Fonctionnalités facultatives

Selon votre avancement, vous pouvez aller plus loin :

- Authentification et gestion des utilisateurs.
- Chat en temps réel avec AdonisJS Transmit.
- Upload de fichiers et d'images.
- Statistiques et graphiques.
- API REST.
- Recherche et filtres avancés.

Ces fonctionnalités sont facultatives. **Le fonctionnement de l'application principale reste prioritaire.**

## Étape 4 : Documenter votre travail

Votre dépôt GitHub devra contenir un fichier `README.md` présentant :

- Le nom et l'objectif de l'application.
- Les fonctionnalités développées.
- Les technologies utilisées.
- Les instructions d'installation et de lancement.
- Un court retour sur l'utilisation de l'IA : outils utilisés, avantages, difficultés rencontrées et éventuelles erreurs corrigées.

Effectuez régulièrement des commits et poussez votre travail sur GitHub.

Pensez à ne jamais publier vos clés API, mots de passe ou fichiers `.env` contenant des informations sensibles.

## Étape 5 : Présenter votre application

Lors de la deuxième séance, chaque étudiant disposera d'environ **5 minutes** pour présenter son travail.

Votre présentation devra aborder :

1. **Le projet :** quelle application avez-vous réalisée et à quel besoin répond-elle ?
2. **La démonstration :** présentez les principales fonctionnalités.
3. **Le fonctionnement technique :** expliquez les modèles, les routes, les contrôleurs et la gestion des données.
4. **L'utilisation de l'IA :** quels outils avez-vous utilisés ? Comment vous ont-ils aidés ?
5. **Le retour d'expérience :** qu'avez-vous appris et quelles difficultés avez-vous rencontrées ?

Vous devez être capables d'expliquer le code et les choix techniques de votre application, y compris lorsque l'IA vous a aidés à les produire.

## Organisation des séances

### Séance 1 : 3h30

- **20 min :** création du dépôt GitHub, transmission de l'URL et choix du projet.
- **30 min :** réflexion sur les fonctionnalités et la structure des données.
- **2h40 :** initialisation et développement de l'application.

**Objectif :** disposer d'une première version fonctionnelle et pousser le code sur GitHub.

### Séance 2 : 3h30

- **1h45 :** finalisation du développement et vérification des fonctionnalités.
- **15 min :** mise à jour du README et dernier push GitHub.
- **1h30 :** présentations individuelles et échanges.

**Objectif :** partager votre réalisation, expliquer son fonctionnement et échanger sur votre expérience de développement avec l'IA.

## Conclusion

L'objectif est d'expérimenter, de développer votre autonomie, de consolider vos connaissances d'AdonisJS et de découvrir comment l'intelligence artificielle peut accompagner le développement d'une application web.

Une application simple, fonctionnelle et comprise vaut mieux qu'un projet complexe que vous ne savez pas expliquer.

**Soyez créatifs, expérimentez et amusez-vous !**
